1. Waarom noem je de eerste HTML-pagina meestal index.html?

Het is een startpunt van waaruit anderen naar andere pagina's of secties kunnen navigeren.

2. Welke HTML-standaard gebruiken webontwikkelaars tegenwoordig en waarom wordt deze een "Living Standard" genoemd?

Webontwikkelaars gebruiken tegenwoordig de HTML Living Standard van de WHATWG

3. Waarom spreken webontwikkelaars tegenwoordig meestal niet meer over één specifieke CSS-versie?

Vanaf CSS3 is de standaard opgesplitst in zelfstandige modules, zoals: Selectors, Flexbox, Grid, Colors, Transforms, Media Queries.Elke module ontwikkelt zich in zijn eigen tempo en heeft eigen niveaus, daarom bestaan er geen speciefieke css-versie.

4.Waarom ziet een website er soms net iets anders uit in verschillende browsers, zoals Chrome, Firefox of Safari?

Want elke brouwer gebruikt verschillende software voor de code van een website en niet elke browser ondersteunt nieuwe functies op hetzelfde moment.
